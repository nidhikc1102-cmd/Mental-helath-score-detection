# Mental-helath-score-detection
Mental Health Score Prediction

A Machine Learning project that predicts a Mental Health Score using factors related to social media usage, academic activities, physical activity, sleep, stress level, and demographic information.

The project uses Python and Scikit-learn to perform data analysis, feature engineering, preprocessing, model training, hyperparameter tuning, and evaluation.

The project compares Linear Regression and Random Forest Regression models and uses RandomizedSearchCV for Random Forest hyperparameter tuning.
